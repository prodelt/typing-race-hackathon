# Local-only scope: three stages first, no backend

The organisers refuse a submission without a complete route through all three stages, count races,
leaderboards and sync as bonuses only after that, and refuse work whose mandatory features depend on a
service that may be down at the demo. So the product is Stage 1 scales, Stage 2 words built only from
unlocked keys, Stage 3 Academy, the dictionary pipeline, weak-key repetition and a deployed URL, with
progress stored in the browser (it must survive a restart). `supabase/` and `apps/web/src/sync/` stay in
the tree, dormant and never executed; races are the first bonus if time remains.
