# 04 Touch-Typing Certification System

Type: grilling
Status: open
Blocked by: none

## Question

How should the certification system be structured to provide tangible value to learners, students, and employers:

1. **Certification Journey & Eligibility**:
   - **Option A (Dedicated Timed Exam with Prerequisites)**:
     - User must first unlock all Stage 1 & Stage 2 keys and complete at least 5 Academy modules.
     - Official Exam: 3 or 5 minutes of continuous typing on unseen, balanced literary/technical text.
     - Strict Zero-Peek blind mode enforced (no visual aids, no on-screen hints).
     - Minimum 97% accuracy required; sub-97% is an automatic fail regardless of speed.
   - **Option B (Cumulative Automatic Unlock)**:
     - Certificate generated automatically once a user completes the curriculum with qualifying averages.

2. **Rank Tiers**:
   - **Level 1 — Basic Touch Typist**: 100–150 SPM (20–30 WPM), $\ge 96\%$ accuracy.
   - **Level 2 — Proficient Typist**: 150–225 SPM (30–45 WPM), $\ge 97\%$ accuracy.
   - **Level 3 — Professional / Working Typist**: 225–300 SPM (45–60 WPM), $\ge 97\%$ accuracy.
   - **Level 4 — Speed Master**: $300+$ SPM ($60+$ WPM), $\ge 98\%$ accuracy.

3. **Certificate Artifacts & Proof**:
   - **Unique Certificate ID & Hash**: e.g., `TR-CERT-2026-UK-84920`.
   - **Public Verification Page**: `https://typingrace.app/verify/<cert_id>` showing date, language, verified SPM/WPM, accuracy %, and blind-mode badge.
   - **Exportable Formats**: High-resolution printable SVG/PDF diploma with QR code linking to verification page, plus OpenGraph badge for LinkedIn/social sharing.

## Options for Human Decision
- Option A (Exam with Tiers + Public Verification URL + PDF/SVG export) (Recommended)
- Option B (Automatic Cumulative)
