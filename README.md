# Typing-Race

Браузерний тренажер сліпого десятипальцевого набору для української (ЙЦУКЕН) та англійської
(QWERTY). Задуманий як система навчання, а не як гра на швидкість: програма має три етапи, кожна
клавіша закріплена за одним пальцем, а після кожної спроби учень бачить рівно одну наступну дію.

Для кого: для тих, хто вчиться друкувати не дивлячись на клавіатуру, за комп’ютером із фізичною
клавіатурою (від 1024 px завширшки; на вужчому екрані застосунок каже, для чого він призначений,
і не вдає, що працює).

## Програма навчання коротко

1. **Етап 1, гами.** Механічні вправи для пальців на вже відкритих клавішах: пробіги домашнім
   рядом, дзеркальні пари, чергування рук, ізоляція одного пальця, вертикальні переходи, Shift і
   цифри, метроном. Текст гам породжується з карти пальців, а не пишеться вручну.
2. **Етап 2, слова з відкритих клавіш.** Слова, складені лише з клавіш, які учень уже засвоїв.
3. **Етап 3, Академія.** Частотні біграми, морфеми, темп.

Клавіша відкривається, коли на вправі, де вона є фокусом, три **залікові** спроби поспіль мають
точність не нижчу за планку. Швидкість нічого не відкриває й нічого не блокує. Докладно і з
обґрунтуваннями: [docs/pedagogy.md](docs/pedagogy.md).

## Що зроблено сьогодні, а що ще ні

Проєкт поділено на п’ять функцій, кожну можна показати окремо
([specs/roadmap.md](specs/roadmap.md)). Готова лише перша.

| Функція | Що в ній | Стан |
|---|---|---|
| F1 `001-typing-core` | клавіатурна модель і карта пальців, рушій натискань, метрики, гами Етапу 1, правило засвоєння, залікова спроба без підказок, локальний прогрес, сторінка формул | **реалізовано** (див. нижче, що ще не закрито) |
| F2 `002-accounts-and-progress` | акаунти, серверний прогрес, історія, експорт | **не почато** |
| F3 `003-words-and-curriculum` | словникова збірка, Етап 2, драбина відкриття клавіш на словах | **не почато** |
| F4 `004-academy-and-analytics` | Академія, адаптивні біграми, теплові карти | **не почато** |
| F5 `005-races-and-leaderboards` | перегони в реальному часі, рейтинги груп | **не почато** |

Що це означає для того, хто відкриває застосунок зараз:

- Є: продуктова сторінка, Сьогодні, Шлях, екран набору (тренувальна і залікова спроби), результат
  з однією наступною дією, картка відкриття клавіші, керований сеанс із трьох блоків,
  налаштування (теми, рух, розмір тексту, мова інтерфейсу), сторінка Формули (її текст:
  [formulas/uk.json](apps/web/messages/formulas/uk.json)) і service worker для роботи без мережі
  після першого завантаження; e2e-перевірки офлайну ще немає.
- Немає: акаунтів, сервера, перегонів, рейтингів, словникових слів, Академії. Прогрес живе лише у
  браузері. Четвертий блок сеансу («справжній текст») прямо названо таким, що з’явиться разом зі
  словами, а не підмінено безглуздими рядками.
- Не закрито всередині F1: наскрізні (Playwright) сценарії прийняття для екранів і аудит
  доступності (axe), перевірка бюджету початкового JS на фінальній збірці, перевірка положень
  `ґ` та апострофа на macOS. Перелік відкритих задач: [tasks.md](specs/001-typing-core/tasks.md).
- Принцип обов’язкового входу ([ADR-0002](docs/adr/0002-mandatory-authentication.md)) у F1
  свідомо призупинено, бо акаунти з’являються лише у F2; це записано в
  [plan.md](specs/001-typing-core/plan.md).

[ADR-0010](docs/adr/0010-twenty-four-hour-challenge-mode.md) фіксує намір зробити всі п’ять функцій
за відведений час. Цей файл описує те, що є в репозиторії, а не намір.

## Як запустити

Потрібні Node 24.19.0 і pnpm (версія закріплена в `packageManager`; `corepack enable` підтягне її).
Жодних змінних середовища, Docker чи акаунтів F1 не потребує.

```bash
pnpm install
pnpm dev            # сервер розробки
pnpm build          # production-збірка; на ній ганяються e2e
pnpm preview        # показати production-збірку локально
```

Перевірки (повний опис: [quickstart.md](specs/001-typing-core/quickstart.md)):

```bash
pnpm typecheck      # tsc --noEmit по всьому робочому простору
pnpm lint           # Biome
pnpm test           # Vitest: модульні й властивісні тести
pnpm test:e2e       # Playwright, Chromium; pnpm test:e2e:all додає Firefox і WebKit
pnpm test:e2e:cdp   # сценарій зі змодельованою фізичною розкладкою ЙЦУКЕН (лише Chromium)
pnpm test:latency   # затримка від натискання до малювання
```

Перший запуск e2e потребує `pnpm exec playwright install --with-deps`.

## Стек: що і чому

| Вибір | Чому |
|---|---|
| Vite + React 19, SPA | клієнтський рендер без сервера; шлях натискання лежить **поза** React ([ADR-0003](docs/adr/0003-react-spa-with-input-engine-outside-the-framework.md)) |
| Прихований `textarea` + `beforeinput`/`compositionend` | єдиний шлях, що читає кирилицю в усіх браузерах і який можна автоматизувати; `keydown` лише для часу |
| pnpm workspace: `engine`, `metrics`, `curriculum`, `domain`, `ui` | `metrics` і `curriculum` без API браузера й Node, щоб той самий код міг виконуватися й на сервері ([ADR-0007](docs/adr/0007-server-recomputes-metrics-with-shared-packages.md)) |
| Zustand і власні типізовані редьюсери | життєвому циклу вправи вистачає написаного вручну редьюсера; XState не використано |
| Tailwind + CSS-змінні («Serene Script») | три теми (світла, темна, для слабкого зору) це набори змінних |
| Paraglide | українська та англійська, типізовані повідомлення |
| Biome | один інструмент на лінт і форматування |
| Vitest, fast-check, Playwright | властивісні тести для формул; справжні події клавіатури в браузері |
| Самостійно розміщені шрифти | без звернень до сторонніх серверів, працює без мережі ([data-sources](docs/data-sources.md#шрифти)) |

Заплановано, але в коді ще немає: Supabase (PostgreSQL, Auth, Realtime, Edge Functions) для F2 і
F5 та Vercel для розгортання.
