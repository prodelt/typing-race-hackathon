# Typing-Race

Браузерний тренажер сліпого десятипальцевого набору для української (ЙЦУКЕН) та англійської
(QWERTY). Задуманий як система навчання, а не як гра на швидкість: програма має три етапи, кожна
клавіша закріплена за одним пальцем, а після кожної спроби учень бачить рівно одну наступну дію.

Для кого: для тих, хто вчиться друкувати не дивлячись на клавіатуру, за комп’ютером із фізичною
клавіатурою (від 1024 px завширшки; на вужчому екрані застосунок каже, для чого він призначений,
і не вдає, що працює).

## Програма навчання коротко

1. **Етап 1, гами.** Механічні вправи для пальців на вже відкритих клавішах: пробіги домашнім
   рядом, дзеркальні пари, чергування рук, ізоляція одного пальця, вертикальні переходи, Shift і
   цифри, метроном. Текст гам породжується з карти пальців, а не пишеться вручну.
2. **Етап 2, слова з відкритих клавіш.** Слова, складені лише з клавіш, які учень уже засвоїв.
3. **Етап 3, Академія.** Частотні біграми, морфеми, темп.

Клавіша відкривається, коли на вправі, де вона є фокусом, три **залікові** спроби поспіль мають
точність не нижчу за планку. Швидкість нічого не відкриває й нічого не блокує. Докладно і з
обґрунтуваннями: [docs/pedagogy.md](docs/pedagogy.md).

## Що працює, а чого немає

Застосунок відкривається й дає пройти повний цикл навчання без сервера й без акаунта: продуктова
сторінка → вибір початкового рівня → «Сьогодні» з однією наступною дією → перевірка розкладки перед
початком (застосунок відмовляється починати українську гаму на англійській розкладці) → екран
набору (тренувальна спроба з підказками, залікова — без них) → результат із метриками, списком
помилок, графіком ритму й однією наступною дією → картка відкриття клавіші. Є керований сеанс із
трьох блоків, три теми (світла, темна, для слабкого зору), налаштування руху й розміру тексту, дві
мови інтерфейсу, сторінка «Формули» (її текст: [formulas/uk.json](apps/web/messages/formulas/uk.json))
і service worker, який дає працювати без мережі після першого завантаження.

Перевірено вживу в браузері головну вимогу §8.2: помилкове натискання підвищує лічильник помилок,
Backspace його не знижує, і після виправлення він лишається підвищеним. Доступність, найкращі
практики та SEO на `/` — по 100 у Lighthouse. Початковий JS у production-збірці: 112.3 КБ gzip при
бюджеті 150 КБ, який ламає збірку в разі перевищення.

Чого немає:

- **Акаунтів і сервера.** Прогрес живе лише в браузері. У `supabase/` лежать схема, дві Edge
  Functions і клієнтський модуль синхронізації, але **жодну міграцію й жодну функцію ще ніколи не
  виконували**: для цього потрібні запущений Docker Desktop і `.env.local`. Нічого з цього не
  доведено.
- **Перегонів і рейтингів.**
- **Слів зі словника й Академії** — тобто Етапів 2 і 3. Четвертий блок сеансу («справжній текст»)
  прямо позначено як такий, що зʼявиться разом зі словами, а не підмінено випадковими рядками.
- **Обовʼязкового входу.** Рішення таке ([docs/adr/](docs/adr/)), але доки немає акаунтів,
  входу теж немає.

## Як запустити

Потрібні Node 24.19.0 і pnpm (версія закріплена в `packageManager`; `corepack enable` підтягне її).
Жодних змінних середовища, Docker чи акаунтів F1 не потребує.

```bash
pnpm install
pnpm dev            # сервер розробки
pnpm build          # production-збірка; на ній ганяються e2e
pnpm preview        # показати production-збірку локально
```

Перевірки:

```bash
pnpm typecheck      # tsc --noEmit по всьому робочому простору
pnpm lint           # Biome
pnpm test           # Vitest: модульні й властивісні тести
pnpm test:e2e       # Playwright, Chromium; pnpm test:e2e:all додає Firefox і WebKit
pnpm test:e2e:cdp   # сценарій зі змодельованою фізичною розкладкою ЙЦУКЕН (лише Chromium)
pnpm test:latency   # затримка від натискання до малювання
```

Перший запуск e2e потребує `pnpm exec playwright install --with-deps`.

## Стек: що і чому

| Вибір | Чому |
|---|---|
| Vite + React 19, SPA | клієнтський рендер без сервера; шлях натискання лежить **поза** React ([docs/adr/](docs/adr/)) |
| Прихований `textarea` + `beforeinput`/`compositionend` | єдиний шлях, що читає кирилицю в усіх браузерах і який можна автоматизувати; `keydown` лише для часу |
| pnpm workspace: `engine`, `metrics`, `curriculum`, `domain`, `ui` | `metrics` і `curriculum` без API браузера й Node, щоб той самий код міг виконуватися й на сервері ([docs/adr/](docs/adr/)) |
| Zustand і власні типізовані редьюсери | життєвому циклу вправи вистачає написаного вручну редьюсера; XState не використано |
| Tailwind + CSS-змінні («Serene Script») | три теми (світла, темна, для слабкого зору) це набори змінних |
| Paraglide | українська та англійська, типізовані повідомлення |
| Biome | один інструмент на лінт і форматування |
| Vitest, fast-check, Playwright | властивісні тести для формул; справжні події клавіатури в браузері |
| Самостійно розміщені шрифти | без звернень до сторонніх серверів, працює без мережі ([data-sources](docs/data-sources.md#шрифти)) |

Заплановано, але в коді ще немає: Supabase (PostgreSQL, Auth, Realtime, Edge Functions) для F2 і
F5 та Vercel для розгортання.
